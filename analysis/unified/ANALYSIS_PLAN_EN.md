# Registered analysis plan

Primary comparison: 200 consecutive, stationarity-approved snapshots for every Kn.
Secondary sensitivity analysis: all available snapshots for ACF, bootstrap, power and exclusion limits.

The field analysis uses half-jump registration and retains only physical support with s/R >= 0.02. The main physics analysis uses temporal coarse-graining, a width-calibrated correlated-noise model, moving-block bootstrap, far-angle covariance, matched synthetic controls and injected-amplitude power curves.

A case is classified as a resolved collective mode only when model preference, out-of-sample prediction, false-discovery calibration, positive-control power, long-range covariance, mode shape and PSD-projection audit all pass. Non-detection is not interpreted as physical absence unless the 90% detection limit falls below the reference low-Kn amplitude.

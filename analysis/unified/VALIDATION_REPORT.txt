Scientific safeguards
---------------------
- Primary POD comparison uses exactly 200 snapshots per Kn.
- Physical support is restricted to s/R >= 0.02.
- Half-jump registration is used.
- SPOD is off by default.
- Full-available records are analyzed separately from common200.
- Non-detection is not interpreted as absence unless the power/exclusion
  analysis demonstrates adequate sensitivity.
- New-case dt_star values are not guessed. They must be resolved from the
  run logs or from exact U_inf and the logged snapshot times.

Important limitation
--------------------
The full nine-case production campaign cannot be executed in this
environment because the user's Windows raw snapshot paths are not mounted.
Shuja must edit the case paths in:
  config/all_kn_campaign_config.json
and run QC before the production analysis.

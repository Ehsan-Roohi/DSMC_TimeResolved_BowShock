# Provenance

- DSMC solver: Bird DS2V with VHS nitrogen and rotational nonequilibrium.
- Geometry: 2-D circular cylinder, D=0.3048 m, M_inf=10, T_inf=200 K, T_w=500 K.
- Marker: density half-jump centre on 60 body-normal rays over 120-179 degrees.
- Physical support: gas-side points only, with s/R >= 0.02 in common comparisons.
- Main temporal analyses use field averaging before nonlinear marker extraction.
- Manuscript v2 uses Ahmad Shoja-Sani as first author and Ehsan Roohi as corresponding author.

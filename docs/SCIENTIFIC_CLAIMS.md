# Scientific claims and boundaries

## Supported

1. Corrected physical-domain instantaneous fields are high rank.
2. A noise-separated collective displacement coordinate is resolved at Kn_D=0.01 and 0.025.
3. The angular mode is nearly invariant while the mean density layer broadens strongly.
4. The collective memory is much longer than local layer-passage and standoff-passage times.
5. Density and pressure retain stronger coherent participation than Mach number and translational temperature.
6. Full-field matched filtering independently validates the marker coordinate.

## Not claimed

1. No critical Knudsen number for disappearance is established.
2. No growing linear instability is claimed.
3. The measured amplitudes are not universal molecular fluctuation levels.
4. The kLST normal-shock eigenmodes are not equated directly with the curved-cylinder covariance mode.

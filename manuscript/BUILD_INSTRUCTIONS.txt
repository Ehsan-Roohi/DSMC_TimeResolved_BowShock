JFM2 manuscript draft V1 - build instructions
==============================================

Required files
--------------
main.tex
references.bib
figures/*.pdf

Local build
-----------
pdflatex -interaction=nonstopmode main.tex
bibtex8 main
pdflatex -interaction=nonstopmode main.tex
pdflatex -interaction=nonstopmode main.tex

On Overleaf, upload the whole ZIP and set main.tex as the main document.
The bibliography backend is BibTeX/natbib. A generated main.bbl is included
as a fallback, but references.bib is the source bibliography.

Notes
-----
- The figure-generation source is included for provenance. It uses local raw-data
  paths from the analysis workstation and therefore requires path updates before reuse.
- Figures are supplied as vector PDF and 400-dpi PNG.
- All PDF figure fonts are embedded TrueType/Type 1; no Type 3 figure fonts remain.

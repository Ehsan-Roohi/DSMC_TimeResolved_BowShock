# Time-resolved rarefied bow-shock dynamics

This repository package accompanies the manuscript **A slow collective displacement coordinate in a broadening rarefied hypersonic bow-shock layer**.

Authors: Ahmad Shoja-Sani (first author) and Ehsan Roohi (corresponding author).

The companion mean-flow paper is available at arXiv:2605.17099. The present manuscript contains the distinct time-resolved covariance, memory, multi-moment synchronization and full-field displacement analyses.

Compile with `latexmk -pdf main.tex`.
